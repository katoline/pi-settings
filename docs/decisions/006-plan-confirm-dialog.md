# 006: 計画の確定ダイアログは残す

- 日付: 2026-11-22
- 状態: 有効

## 背景

取り込み元では、pi が作業を始める前に計画（完了条件つきのチェックリスト）を出し、「確定する / 修正を依頼する / 中止する」をダイアログで選ばせる。確定すると `ask_user`（質問ツール）が外れ、最後まで質問せずに走る。

## 決定

- 計画の確定ダイアログは残す

## 理由

- 依頼した直後、ユーザーが画面の前にいるときに 1 回出るだけ
- ここで要件をそろえておくと、その後の自律実行がぶれない

## 却下した案

- 計画を自動で確定してすぐ走らせる案：要件がずれたまま最後まで進む恐れがある
