# 001: `agent/` を `~/.pi/agent` と同じ構成にしてリンクで使う

- 日付: 2026-11-22
- 状態: 有効

## 背景

pi の設定・拡張・スキルはエージェントディレクトリ `~/.pi/agent` に置く。リポジトリ側の置き場所が実際の構成と違うと、どこに何を置けば効くのかが分かりにくくなる。

## 決定

- `agent/` を `~/.pi/agent` と同じ構成にする（`AGENTS.md`・`extensions/`・`skills/`・`settings.json`）
- `~/.pi/agent` 配下からシンボリックリンクで参照する。拡張とスキルはディレクトリごとリンクし、追加したものがそのまま読み込まれるようにする
- このリポジトリで作業するときの指示（ルートの `AGENTS.md`、`CLAUDE.md` はそのリンク）と、pi のグローバル指示（`agent/AGENTS.md`）はディレクトリで分ける。pi は作業ディレクトリとその親の `AGENTS.md` を読むため、`agent/` に入れておけば二重に読まれない

## 理由

- 編集がそのまま手元の pi に効き、コピーのずれが起きない
- pi のドキュメントの置き場所の規約がそのまま使える

## 却下した案

- `extensions/` をリポジトリ直下に置く案：実際の構成と違い、ややこしい（ユーザーの指摘で変更）
- pi パッケージとして `pi install` で入れる案：リンクと併用すると拡張が二重に読み込まれる。`package.json` の `pi` 欄はパッケージとして配る場合のために残す
