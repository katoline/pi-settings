# 010: Mac の音声入力は自前の拡張で作る（別途、個別に進める）

- 日付: 2026-11-22
- 状態: 計画中（2026-11-23 から保留）

## 背景

Mac で pi を使うときに音声で入力したい。音声入力では「えー」「あの」などのノイズや言い直しが混ざるので、軽く整えてから入力したい（大きく書き換えない）。

## 決定

- pi の拡張として作る（録音 → 文字起こし → 軽い整形 → 入力欄へ挿入。送信はしない）
- インストールが必要なもの（録音・文字起こしのツール、文字起こしのモデル）の入れ先を吟味する必要があるため、ハーネスの取り込みとは別に、個別にテストしながら進める
- 計画は [plan/voice-input.md](../plan/voice-input.md)

## 理由

- 整え方と、送信前に確認する流れを自分好みにできる

## 却下した案（現時点）

- Aqua Voice などの Mac アプリを使う案：作らずに済み、つなぎ言葉の除去もするが、整え方を調整できない（選択肢としては残す）
