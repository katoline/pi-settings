# 音声入力（Mac）

## 概要

Mac で pi に音声で入力できるようにする。録音 → 文字起こし → 軽い整形 → 入力欄へ挿入（送信はしない）。インストールするものの入れ先を吟味する必要があるため、ハーネスの取り込みとは別に、個別にテストしながら進める。

## 関連

- 決定：[010](../decisions/010-voice-input-own-extension.md)
- pi の API：[reference/pi-api-notes.md](../reference/pi-api-notes.md)（`registerShortcut`・`setEditorText`・`pasteToEditor`・`modelRegistry.complete`）
- 状態：計画のみ（2026-11-22）

## 要件

- ショートカットキーで録音を開始・停止する
- 状態をフッターに出す（例：「🎙 録音中 0:05」→「文字起こし中…」→「整えています…」）
- 文字起こしした文を軽く整えてから、入力欄に入れる。送信はユーザーが確認して Enter で行う
- 整えるときに消すもの：つなぎ言葉（「えー」「あの」「えっと」）、言い直し（例：「例えば、あ、例えば」→「例えば」）、聞き間違いのノイズ
- 整えるときにしないこと：言い回しの変更、内容の追加、要約
- 整える前の文に戻せるようにする（例：コマンドで直前の生の文字起こしを入力欄に戻す）

## 構成案

| 部分 | 案 | 備考 |
| --- | --- | --- |
| 録音 | `ffmpeg`（`-f avfoundation`）または `sox` | 今の Mac には未インストール |
| 文字起こし | 手元の whisper.cpp（`whisper-cli`）＋ large-v3-turbo モデル | 音声を外部に送らず、追加料金なし。Apple Silicon で速い。モデルは約 1.6GB |
| 整形 | `ctx.modelRegistry.complete` で安いモデルに整形させる | 候補：OpenCode Go の DeepSeek V4.1 Flash（サブスク内）、Claude Haiku 5.5（従量だが少額） |
| 入力 | `ctx.ui.setEditorText` / `pasteToEditor` | 送信はしない |
| 起動 | `pi.registerShortcut` | pi の既存キー割り当てと衝突しないキーを選ぶ |

## 決めること

- [ ] 録音・文字起こしのツールの入れ先（dotfiles の Nix 設定に足す／このリポジトリの devShell／その他）。`darwin-rebuild` はユーザーが実行する
- [ ] 文字起こしのモデルファイルの置き場所（例：`~/.cache/` 配下）と取得方法
- [ ] 文字起こしを手元（whisper.cpp）にするかクラウドにするか
- [ ] 整形に使うモデル（DeepSeek V4.1 Flash か Haiku 5.5 か）
- [ ] ショートカットキー
- [ ] 既存の pi 用音声拡張を参考にするか（Mac 専用の picrophone など。導入前にソースを読む）

## テスト計画（個別に進めるときの目安）

- [ ] 録音：マイクの許可（初回はターミナルアプリにマイクの使用許可が要る）、開始・停止、無音の扱い
- [ ] 文字起こし：日本語のサンプル音声で精度と所要時間を測る（短文・長文・専門用語・コマンド名を含む文）
- [ ] 整形：つなぎ言葉・言い直し・ノイズの入った文字起こしの例を集め、期待する出力と比べるテスト表を作る。言い回しを変えない・内容を足さないことを確かめる
- [ ] 入力：入力欄に入るだけで送信されないこと、生の文に戻せること
- [ ] 失敗時：ツールが無い・モデルが無い・整形の API が失敗したときに、生の文字起こしを入力欄に入れて知らせる

## 作らない場合の選択肢

- Aqua Voice などの Mac アプリ（どのアプリでも音声入力でき、つなぎ言葉も消す。整え方は調整できない）
